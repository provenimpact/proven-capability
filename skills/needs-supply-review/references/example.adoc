= Supply Review Example

This file shows a supply chain review cycle for the canonical e-commerce scenario.

== Context

Given:

* TypeScript/Next.js e-commerce application
* `package.json` with 47 direct dependencies
* `docs/constraints.adoc` with:
  - Security constraint: "No dependency with a known CRITICAL or HIGH CVE may remain unpatched for more than 7 days"
  - Licensing constraint: "Only MIT, Apache-2.0, and BSD-licensed dependencies are permitted"
  - Supply chain constraint: "All direct production dependencies must have a current supply review (reviewed within 180 days)"
